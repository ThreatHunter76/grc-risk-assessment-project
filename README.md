# Cybersecurity Risk Assessment Project For ASBank Finance Limited.

## Overview
This project simulates a cybersecurity risk assessment conducted on a financial institution known as ASBANK Financial Ltd . The assessment identifies organizational cyber risks, evaluates threats and vulnerabilities, and recommends mitigation strategies aligned with industry best practices.

## Skills Demonstrated
- Governance, Risk, and Compliance (GRC)
- Risk Analysis
- Cybersecurity Documentation
- Security Governance
- Mitigation Planning

## Project Files
- Risk Assessment Report
- Risk Register
- Security Recommendations

## Framework References
- ISO 27001
- NIST Cybersecurity Framework
